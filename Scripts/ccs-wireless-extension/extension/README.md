# Motor Balance Car Wireless Flash

CCS Theia commands for the existing CMSIS-DAP/OpenOCD batch files in the
`motor_balance_car` project.

- `Wireless: Probe Test` calls `Scripts/wireless_probe_test.bat`.
- `Wireless: Flash` calls `Scripts/wireless_flash.bat`.
- `Wireless: Build + Flash` calls `Scripts/build_and_wireless_flash.bat`.

`Ctrl+Shift+B` runs `Wireless: Build + Flash`.
